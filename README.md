# Sakila Movie Finder

Интерактивное консольное приложение на Python для поиска фильмов в базе
данных **Sakila (MySQL)**. История поисковых запросов сохраняется в
**MongoDB**, а пользователь может посмотреть 5 самых популярных
запросов.

## 🎯 Цель проекта

Цель проекта --- создать простое интерактивное консольное приложение для
поиска фильмов.

Основные возможности:

-   поиск фильмов по названию или ключевому слову;
-   поиск фильмов по жанру и диапазону годов выпуска;
-   вывод результатов по 10 фильмов;
-   возможность показать следующие 10 результатов;
-   сохранение каждого поискового запроса в MongoDB;
-   вывод Top-5 самых популярных поисковых запросов.

## 🛠 Технологический стек

-   **Python 3.x**
-   **MySQL** --- хранение данных о фильмах
-   **Sakila** --- учебная база данных
-   **MongoDB** --- хранение истории поиска
-   `mysql-connector-python`
-   `pymongo`

## ⚙️ Инструкция по установке и запуску

### 1. Python

Рекомендуется использовать **Python 3.13**.

Проверить версию:

``` bash
python --version
```

### 2. Установка библиотек

В терминале проекта выполните:

``` bash
python -m pip install mysql-connector-python pymongo tabulate
```

Отдельно устанавливать пакет `bson` не нужно, так как необходимый модуль
уже входит в `pymongo`.

### 3. Подключение MySQL

Необходимо установить MySQL и импортировать учебную базу данных
**Sakila**.

В файле `local_settings.py` укажите параметры подключения:

``` python
dbconfig = {
    "host": "localhost",
    "user": "YOUR_MYSQL_USER",
    "password": "YOUR_MYSQL_PASSWORD",
    "database": "sakila"
}
```

Замените `YOUR_MYSQL_USER` и `YOUR_MYSQL_PASSWORD` своими данными.

### 4. Подключение MongoDB

Для истории поиска используется MongoDB.

В `local_settings.py` укажите строку подключения:

``` python
MONGODB_URL_ATLAS = "YOUR_MONGODB_CONNECTION_STRING"
```

Пользователь MongoDB должен иметь права **readWrite** для базы данных,
используемой проектом.

> Не публикуйте реальные пароли и MongoDB connection string в публичном
> GitHub-репозитории.

### 5. Запуск программы

Из папки проекта выполните:

``` bash
python main.py
```

После запуска откроется главное меню.

``` text
3. Show top 5 popular searches

```

### Пример 1 --- поиск по названию

``` text
Choose an option: 1
Enter a movie title or keyword: dino

Movies found: 3

+----+----------------------+-------------+------+--------+----------+
| No | Title                | Description | Year | Length | Category |
+----+----------------------+-------------+------+--------+----------+
| 1  | ...                  | ...         | ...  | ...    | ...      |
+----+----------------------+-------------+------+--------+----------+

Show the next 10 results? (y/n):
```

Количество и содержание результатов зависят от данных в базе Sakila.

### Пример 2 --- поиск по жанру и году

``` text
Choose an option: 2

Available genres:
1. Action
2. Animation
3. Children
...

Available years: 2005 - 2006

Enter genre ID: 1

Enter end year: 2006

Movies found: 10
```

Для поиска по одному конкретному году можно указать одинаковые значения
начального и конечного года.

### Пример 3 --- Top-5 популярных запросов

``` text

TOP 5 POPULAR SEARCHES

Search type       Parameters                   Searches
-------------------------------------------------------

```

Статистика зависит от реальной истории запросов, сохраненной в MongoDB.
